常见组合调用

现实问题通常不是调用一张卡，而是一组原子沿着固定顺序协同工作。

工作不稳定 / 想辞职

先看能力，再看退出缓冲和最坏结果，最后用行动制造市场反馈。

可迁移能力 → 选择权 → 可重启 → 反馈循环
父母催婚

先拆默认脚本，再确认自己要什么，并接受不同选择各自的代价。

社会叙事 → 叙事主权 → 主体性 → 意义
关系长期消耗

先恢复自己的主语，再检查边界、双向参与和离开后的重启能力。

主体性 → 边界 → 双向关系 → 可重启
努力但越来越迷茫

把“很累”从价值判断中拿掉，改看反馈、能力和最终生活目标。

反馈 → 反苦难 → 反努力 → 反成功
焦虑与内耗

区分事实和叙事，把不属于自己的责任还回去，再恢复行动权。

社会叙事 → 主体性 → 边界 → 反馈 → 快乐
孩子教育

不是替孩子设计人生，而是让安全感、能力感和自主性逐步形成。

主体性 → 能力 → 可重启 → 关系支持
钱够了但生活没感觉

财富完成缓冲功能以后，继续积累不一定继续增加自由。

选择权 → 反成功 → 快乐 → 生命体验
人生意义感下降

先停止用外部成功定义意义，再把时间重新投向有感受的生活。

反成功 → 快乐 → 生命体验 → 自我赋义
