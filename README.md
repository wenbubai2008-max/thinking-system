# Thinking System

个人思想框架知识库。

当前首页包含“墨苍离”两套独立框架：

- **2024+ 成熟期**：认知工程、叙事与自我、行动与反馈、关系结构、概率主义、选择权。
- **2024以前**：祛魅、心理资源、先不出局、边界与责任、信息优势、止损与环境切换。

## 使用

直接打开根目录 `index.html`。

如果启用 GitHub Pages：

1. 进入仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选择 **main**，目录选择 **/(root)**
4. 保存后即可得到公开网页地址。

后续可以继续增加其他作者/思想体系，并把首页扩展为多思想系统入口。
